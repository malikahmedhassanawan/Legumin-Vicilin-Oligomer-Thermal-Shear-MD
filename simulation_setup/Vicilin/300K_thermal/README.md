# Vicilin trimer: 300 K thermal runs

Two independent replicates, identical except for the random seed used to generate starting velocities in the NVT step:

| Folder | Replicate | NVT gen-seed |
|---|---|---|
| Run_1 | r1 | 111 |
| Run_2 | r2 | 222 |

Each folder contains the NVT, NPT and production .mdp/.tpr files for that replicate. Energy minimisation and ion files, topology and starting structures are in [Common files](https://github.com/malikahmedhassanawan/Legumin-Vicilin-Oligomer-Thermal-Shear-MD/tree/main/simulation_setup/Vicilin/Common%20files).
